BRC Vault changes
=================
Version numbers: last number for fixes and wording, middle number for new
features, first number for changes to file formats or the security model.
Test builds carry "-test.N" and are never published.

1.2.0 (Nov 7, 2026)
  - 中文: an English / 中文 button in the top bar shows the whole page in
    Simplified Chinese, including the paper backup's instructions. A browser
    set to Chinese opens in Chinese; the choice is remembered on this device
    (?lang=en or ?lang=zh in the link also works). Asked for by the Chinese
    BrowserCoin community.
  - It only changes words. Keys, addresses, backup codes, recovery words,
    file names and anything you type are never touched, and the files Vault
    makes are identical in either language (tested: a backup made and
    restored in Chinese gives back the exact wallet file). The same small
    switch (src/i18n.js) is in BRC Post and BRC Pulse. The BrowserCoin app's
    own menu names (Settings → Export key…) stay in English, as the app shows
    them.

1.1.2 (Oct 31, 2026)
  - The whole BRC Works family: BRC Post in the top switcher (Vault · Post ·
    Pulse) and the footer ("Vault keeps it · Post seals it · Pulse checks
    it"). The rule line reads the same as Pulse and Post.

1.1.1 (Oct 31, 2026)
  - Release: BRC Seal is BRC Post everywhere; a restored mailbox points to
    BRC Post; and the review fixes below (reviewed before release).
  - test.3: fixes from the "it just works" review (Oct 31). On a phone,
    Restore no longer runs off the right edge once a backup is loaded (file
    name and address now fit). Pasting a bare 64-character code on Back up
    asks "Is this your secret key, or your address?" with two buttons
    instead of a tick box; "No, I pasted my address" explains that the
    wallet file is what's needed (Settings → Export key…). The status pill
    says "Sends nothing" (or "Offline: safest") instead of a grey "Online".
    "Protection" reads "Locked with your password". A new wallet ends with
    one tap to the next step: See it on BRC Pulse, or Open BRC Post for a
    mailbox. The Holding coins choice says the app holds one wallet at a time.
  - test.2: a mailbox restored in Restore now says what to do with it: step 3
    becomes "Use it in BRC Post", with Open BRC Post and Save the locked
    mailbox file, and explains that the 64-character code is the public
    address, which can't open anything (Patrick pasted it into Post as a key).
    The family line reads "Post seals it".
  - test.1: BRC Seal is now BRC Post: "Mailbox key for BRC Post", and every
    other mention.

1.1.0 (Oct 31, 2026)
  - Release: fixes from a pre-launch review of New wallet: the password and
    purpose are locked while the key is made; Clear page and Make another
    each need a second press while an unsaved new wallet is on the page;
    opening the print preview only counts as saved once printing starts.
  - test.2: New wallet is its own tab (Back up · Restore · + New wallet),
    no longer a choice inside Back up, which is now only for wallets you
    already have. Making a wallet and backing it up are one step: choose
    what it's for and a password, press Make my wallet, and the key is
    created, locked, test-opened and wiped from the page in one go. It is
    never shown or saved unlocked, and the address appears with the backup.
    Closing the page or making another before the backup is downloaded or
    printed asks first. #new opens the tab; #new-mailbox opens it set to a
    mailbox key. Arrow keys move both ways between tabs.
  - Fixes from the Fable 5.1 security review (Oct 31): a mailbox key is never
    turned into a wallet file, recovery words or an unprotected paper wallet;
    a new wallet's key is wiped once its backup is locked.
  - The address picture (same in Seal and Pulse), from SHA-256 of the address.
  - The BRC Works rule and keep it / check it in the footer.
  - Make a new wallet: a fresh key made on the page that goes straight into a
    locked backup. Its key is never shown or saved unlocked.
  - Mailbox keys: a new wallet can be made as a mailbox key for BRC Seal. Its
    backup has its own type (brc-vault-mailbox-key, paper code BRCMBOX1), bound
    into the encryption so a coin backup can't be relabelled as one.
  - Restore names a mailbox key and says what it is for.
  - The version is shown in the footer next to the build code.

1.0.0
  - Password-protected backups, paper backups with per-line checks, restore to
    a BrowserCoin wallet file, recovery words, desktop wallet files, QR scan.
